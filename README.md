# 📎 Project Name : Smart Maintenance Management System (SMMS)
### نظام ذكي لإدارة الصيانة

📌 Project Overview:
Smart Maintenance Management System is a centralized web platform designed to manage all maintenance operations for organizations such as factories, companies, schools, universities, and hospitals.
Instead of traditional methods (phone calls or messages), employees can log in to the system and create a Maintenance Request directly. The system will track the request, assign technicians, and monitor the maintenance lifecycle until completion.

🎯 Project Objectives:
- Digitize and centralize the maintenance request process.
- Reduce response time and improve communication between employees and maintenance team.
- Track all requests status (Pending, In Progress, Completed).
- Assign technicians automatically/manually based on specialty.
- Generate reports and analytics for maintenance performance and costs.
- Create a history log for all equipment and maintenance activities.

📦 Project Scope:
- **For Employees:** Create maintenance requests with description, location, priority, and attach images.
- **For Maintenance Manager:** Dashboard to view all requests, assign tasks to technicians, track progress, and manage inventory/spare parts.
- **For Technicians:** Receive assigned tasks, update status, add notes and repair costs.
- **For Admin:** Manage users, departments, equipment list, and generate reports.

- **Core Features:** User Authentication & Roles, Request Management, Real-time Notifications, Dashboard & Analytics, Equipment History.
